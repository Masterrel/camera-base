Камери швидкості — Політика конфіденційності

Набуває чинності: 27 жовтня 2026 р.

Ця політика описує, як застосунок «Камери швидкості» (далі — «застосунок») поводиться з даними користувача. Застосунок попереджає про стаціонарні камери контролю швидкості на шляху руху.

Які дані використовуються

  • Геолокація (точна). Використовується лише під час відстеження (від натискання START до натискання STOP) або поки відкрито екран «Радар», щоб визначати відстань до найближчих камер. Координати обробляються тільки на пристрої: не зберігаються в історії, не надсилаються розробнику чи третім особам.
  • Налаштування застосунку (гучність сигналів, стан бази камер тощо) зберігаються лише на пристрої.

Що застосунок НЕ робить

  • Не вимагає реєстрації чи облікового запису.
  • Не збирає персональні дані, контакти, фото чи файли.
  • Не містить реклами та сторонніх сервісів аналітики чи відстеження.
  • Не передає дані про ваше місцеперебування через інтернет.

Доступ до інтернету

Інтернет використовується тільки для завантаження оновлень бази камер — після того, як користувач сам натисне кнопку оновлення. База завантажується з публічного репозиторію на GitHub. Під час такого запиту GitHub, як і будь-який вебсервер, отримує технічні дані з'єднання (наприклад, IP-адресу) відповідно до політики конфіденційності GitHub. Жодні дані про вашу геолокацію при цьому не передаються.

Дозволи

  • Геолокація — визначення відстані до камер.
  • Сповіщення — попередження про камери та індикація роботи відстеження.
  • Показ поверх інших програм — короткий напис про камеру поверх навігатора.
  • Засвічення екрана — увімкнення екрана при наближенні до камери.
  • Інтернет — оновлення бази камер.

Джерело даних про камери

Дані про камери: © учасники OpenStreetMap, ліцензія ODbL.

Діти

Застосунок не призначений для дітей і свідомо не збирає жодних даних про них.

Зміни політики

«Камери швидкості» (Speed Cameras) — Privacy Policy

Effective date: October 27, 2026

This policy describes how the «Камери швидкості» (Speed Cameras) app (“the app”) handles user data. The app warns drivers about fixed speed cameras ahead.

Data used

  • Precise location. Used only while tracking is on (from START until STOP) or while the Radar screen is open, to calculate the distance to nearby cameras. Location is processed on the device only: it is not stored as history and is not sent to the developer or any third party.
  • App settings (alert volume, camera database status, etc.) are stored on the device only.

What the app does NOT do

  • No registration or account.
  • No collection of personal data, contacts, photos or files.
  • No ads, no third-party analytics or tracking SDKs.
  • No transmission of your location over the internet.

Internet access

The internet is used only to download camera database updates, when the user taps the update button. The database is downloaded from a public GitHub repository. As with any web server, GitHub receives technical connection data (such as the IP address) under the GitHub Privacy Statement. No location data is sent.

Permissions

  • Location — distance to cameras.
  • Notifications — camera alerts and tracking status.
  • Display over other apps — short camera label over the navigation app.
  • Full-screen intent — turning the screen on when approaching a camera.
  • Internet — camera database updates.

Camera data source

Camera data: © OpenStreetMap contributors, ODbL license.

Children

The app is not directed at children and does not knowingly collect any data about them.

Changes

Any changes will be published on this page with an updated effective date.
